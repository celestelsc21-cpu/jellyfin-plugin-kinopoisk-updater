# Jellyfin.Plugin.KinopoiskUpdater

Плагин Jellyfin 10.11.x: Кинопоиск как источник метаданных и изображений для фильмов,
сериалов и эпизодов. Обновление — стандартной командой Jellyfin «Обновить метаданные».

Данные берутся из неофициального API [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech);
нужен API-ключ этого сервиса.

## Что обновляется

| Элемент | Поля |
|---|---|
| Фильм, сериал | название, оригинальное название, описание, слоган, год (у сериала — год начала), дата премьеры, возрастной рейтинг (`16+`), рейтинг Кинопоиска, жанры, страны, IMDb id, статус сериала, актёры (до лимита из настроек) и съёмочная группа |
| Эпизод | название (рус., иначе англ.), оригинальное название, описание, дата выхода; файлы из нескольких серий (`S01E09-E10`) получают названия через « / » |
| Изображения | постер (основное), обложка (фон), логотип |

Поля, которые в Кинопоиске пустые, не затираются. Сезоны Кинопоиск не описывает:
обновление сезона обновляет его эпизоды.

## Установка

1. Панель управления → Плагины → Репозитории → добавить
   `https://raw.githubusercontent.com/celestelsc21-cpu/jellyfin-plugin-kinopoisk-updater/manifest/manifest.json`.
2. Каталог → **Kinopoisk Updater** → Установить, перезапустить Jellyfin.
3. Мои плагины → Kinopoisk Updater → ввести **API-ключ** → Сохранить.

## Настройка медиатеки (один раз)

Панель управления → Медиатеки → медиатека → «Изменить»:

- **Загрузчики метаданных** для фильмов, сериалов и эпизодов: включить **Kinopoisk** и
  поднять на первое место. Тогда Кинопоиск главный, а TMDb и другие источники
  дополняют поля, которых в Кинопоиске нет.
- **Загрузчики изображений** для фильмов и сериалов: включить **Kinopoisk** и поднять
  наверх (если нужны постеры Кинопоиска).
- Язык метаданных можно оставить любым: данные Кинопоиска всегда на русском.

## Как обновлять

- Фильм / сериал / сезон / эпизод → «⋮» → **«Обновить метаданные»** →
  «Заменить все метаданные»; для постера — ещё «Заменить существующие изображения».
  Обновление сериала затрагивает все его эпизоды, сезона — его эпизоды.
- Найден не тот фильм или ничего не найдено → «⋮» → **«Определить»** → выбрать вариант
  из Кинопоиска либо вписать id в поле «Kinopoisk» (число из ссылки
  `kinopoisk.ru/film/12345/` или `/series/12345/`).
- Эпизоды находятся по номерам сезона и серии внутри сериала, у которого уже есть id
  Кинопоиска. Сначала обновите (или «Определите») сам сериал.

Автоматически, без выбора пользователя, применяется только уверенное совпадение:
тот же тип (фильм/сериал) и год ±1, а без года — точное совпадение названия.
Иначе элемент не меняется — используйте «Определить».

## Ограничения

- Бесплатный ключ имеет дневной лимит запросов. Одно обновление фильма — 3 запроса
  (карточка, премьеры, люди); все эпизоды сериала — 1 запрос; ответы кэшируются на 30 минут.
- Когда лимит исчерпан или API недоступен, в лог пишется предупреждение, элементы не меняются.
- Номера сезонов и серий должны совпадать с Кинопоиском.

## Логи

Docker: `docker logs <контейнер> 2>&1 | grep -i kinopoisk` или файлы
`/config/log/log_*.log` внутри volume. Ошибки ключа и лимита пишутся как предупреждения.

## Требования и сборка

- Jellyfin Server **10.11.x** (собрано против 10.11.11, `targetAbi` 10.11.0.0).
- .NET SDK 9.0.200+ (нужен для `.slnx`).

```
dotnet test -c Release
dotnet publish Jellyfin.Plugin.KinopoiskUpdater/Jellyfin.Plugin.KinopoiskUpdater.csproj -c Release -o out
```

Ручная установка: `Jellyfin.Plugin.KinopoiskUpdater.dll` в
`/config/plugins/Kinopoisk Updater_<версия>/` (Docker) и перезапуск.

При push в `main` GitHub Actions собирает и тестирует плагин; если версии из
`build.yaml` ещё нет в релизах — публикует zip и обновляет `manifest.json`
в ветке `manifest`.
